    How a button press goes live

    Publish and Retire start a Claude Code session on your account. It takes the wallpaper from this dashboard, checks it compiles, pushes to main and marks the request done here. The app picks it up within minutes. If the session can't start from here, the request waits until the next Claude Code session on the catalog repo, which carries it out first.

    What people like

    LiveWalls collects no usage data: no analytics, accounts or tracking, as its privacy policy promises. There are no favourites or apply counts to show yet. These are the ways to get them, from least to most change.

    Google Play Console

    No app change
    • Installs, uninstalls and active devices per day
    • Ratings and review text, which often name favourite wallpapers
    • Download the CSV reports and give them to Claude to chart here

    Anonymous popularity counts

    App release + privacy policy update
    • One anonymous "applied" ping per wallpaper, no device id
    • Ranks wallpapers by how often they're set and kept
    • Opt-in, so it keeps the no-tracking promise

    In-app hearts

    App release
    • A heart on each wallpaper page
    • A "Most loved" row in the gallery
